# Nexa

**Lead operating system.** Capture → score → route → sequence → daily action list.

Brand-agnostic. Multi-tenant. HubSpot-first. Built so any agency or sales team can drop it in and work leads without noise.

---

## What it does

| Layer | Purpose |
|-------|---------|
| **Capture** | Public forms + referral links land leads into a workspace |
| **Score** | Deterministic scoring (company, phone, source, agency signals) |
| **Route** | Status pipeline + priority queue |
| **Sequences** | Onboard / nurture / re-engage enrollment |
| **Today** | 3–5 highest-leverage actions for the day |
| **HubSpot** | Create-or-update contacts from captures (first-class) |
